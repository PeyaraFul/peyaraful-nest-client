# 🏡 Peyaraful Nest

**Peyaraful Nest** is a modern full-stack rental property platform built with the MERN stack. It connects property owners and tenants through a secure, user-friendly system where owners can add properties, tenants can discover and book them, and administrators can manage the entire platform.

---

## 🌐 Live Demo

- **Client:** https://peyaraful-nest-client.vercel.app


> Replace the URLs above with your deployed links.

---

## ✨ Features

### 🏠 Property Management
- Owners can add rental properties
- Update property information
- Delete pending properties
- Upload property images
- Property approval workflow

### 🔍 Smart Property Search
- Search by location
- Filter by property type
- Filter by minimum and maximum rent
- Sort by rent (Low → High / High → Low)

### 📅 Booking System
- Tenants can book available properties
- Prevent duplicate bookings
- Booking status management
- Owner approval system

### 💳 Secure Payment
- Stripe Payment Integration
- Secure checkout process
- Payment history
- Booking confirmation after successful payment

### 📱 Responsive Design
- Mobile Friendly
- Tablet Friendly
- Desktop Optimized
- Modern UI

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/peyaraful-nest.git
```

---

## Client Setup

```bash
cd client
npm install
npm run dev
```

---

## Server Setup

```bash
cd server
npm install
npm start
```

# 🔑 Environment Variables

## Client (.env.local)

```env

NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
```

